# VG X Labyrinten

Dette er en enkel kopi av VG X som dere kan bruke som utgangspunkt. 🚀

Prosjektet består av:

- `backend` ⚙️: serverer feed-data fra en JSON-fil
- `web-app` 📱: viser feeden i en fullskjerms scroll-opplevelse

Feeden er bygd opp av ulike typer items. 🧩

I dag støtter den:

- stories
- videoer

Men dere kan enkelt legge til flere typer senere, eller finne på egne feed-items hvis dere vil. 🎨

Start prosjektet slik:

```bash
cd backend
npm install
npm run dev
```

```bash
cd web-app
npm install
npm run dev
```

Feed-dataene ligger i: 🗂️

```bash
backend/data/feed.json
```
